PRIMARY TASK F, PART 1 - 5 FUNCTIONS (Day 3 - DO THIS FIRST)
------------------------------------------------------------------
Create Database/Functions/08_CreateFunctions.sql:

1. ufnCustomerAge(@CustomerID INT) RETURNS INT
   Calculate age from Customer.DateOfBirth (or just return the
   stored Age column if your team decided to trust it - document
   which approach you used).

2. ufnCustomerLifetimeValue(@CustomerID INT) RETURNS DECIMAL(12,2)
   SUM of TransactionTotal from SalesTransaction for that customer.

3. ufnAveragePurchase(@CustomerID INT) RETURNS DECIMAL(10,2)
   AVG of TransactionTotal from SalesTransaction for that customer.

4. ufnCampaignResponseRate(@CustomerID INT) RETURNS DECIMAL(5,2)
   Percentage: (COUNT of CampaignResponse where
   PurchaseCompleted = 1) / (COUNT of all CampaignResponse) * 100
   for that customer. Return 0 (not NULL, not error) if the
   customer has zero campaign responses.

5. ufnDaysSinceLastPurchase(@CustomerID INT) RETURNS INT
   DATEDIFF(DAY, MAX(TransactionDate), GETDATE()) from
   SalesTransaction for that customer. Return NULL or a large
   sentinel value if the customer has zero transactions - document
   your choice.

Test each function individually:
  SELECT dbo.ufnCustomerAge(1), dbo.ufnCustomerLifetimeValue(1), etc.
against a few real CustomerIDs to confirm sane output before
telling Lien they're ready.
