DATABASE NAME & CORE RULES (apply to everyone)
------------------------------------------------------------------
- Single SQL Server database: CustomerCampaignAnalytics
- Schema: dbo only
- Naming: tables singular (Customer), views vw*, procs usp*,
  functions ufn*, PK_<Table>, FK_<Parent>_<Child>, IX_<Table>_<Col>
- No hardcoded passwords/connection strings anywhere in code or repo
- SQL Server is the single source of truth. Ollama never touches
  SQL directly (only Python talks to Ollama). Power BI is read-only.
- Historical data is never deleted.
- Everything must be re-creatable from the scripts in the repo -
  no manual/GUI-only changes.
